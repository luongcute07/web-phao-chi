# web-phao-chi

Website for Phào Chỉ Thạch Cao & Xi Măng GFRC Quảng Bình, built with Next.js, React, and Tailwind CSS.

## Run locally

Requirements: Node.js and npm.

```powershell
cd frontend
npm install
npm run dev
```

Open http://localhost:3000.

To create a production build, run `npm run build` from `frontend`.
